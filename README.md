# explain-in-plain-words — 把指定内容用人话说明白

面向没看过原文但愿意把这段读完的读者，把指定材料用人话讲清楚：交代清楚背景、本体、各部分连接关系以及不能说死的边界，严守「说明白优先于好读、不删条件、不补材料外信息、前后相接散文推进」的写作规范。

## 功能列表 / 触发条件

- **触发词**：`用人话说明白`、`把这段讲清楚`、`人话解释`、`说人话`、`讲明白`、`explain in plain words`、`explain-in-plain-words`
- **核心能力**：
  1. 交代四件事：所处背景（针对什么问题、成立条件、易混相邻概念）、到底是什么、各部分如何连接、哪些地方不能说死
  2. 严守信息边界：只用材料已有信息，不垫时代大背景，不脑补未写出的原因/数字/动机，直指原文含糊或不一致处
  3. 概念精准化：保留专有名词原词，首次出现用完整句说明定义与易混概念差异，先定义后比喻
  4. 散文式推进：默认写成前后相接的散文，按「前提 → 判断 → 所靠条件」把逻辑写完，禁用空洞套话与删条件式总结
